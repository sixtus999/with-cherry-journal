Questions

Can we both write in the same diary?

Yes. One of you creates it, then invites the other with a one-time link. You both add and edit pages.

Is our diary private?

Only the two of you can edit. Anyone with the link can read, and you control the link.

Do I need to install anything?

No. It runs in any modern browser.
